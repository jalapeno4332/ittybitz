# v3.0.3 🦕 Iguanodon — a permanent Download link

A small follow-up to [v3.0.2](v3.0.2.md). The cryptography and the recovery tool are unchanged.

## Changes

- **Download link in the footer.** Getting the app as a file previously depended on the banner at the top of the page — which is dismissible, so once it was gone the app offered no route to its own downloadable copy. The footer now carries a permanent **Download app** link, beside the Recovery tool and GitHub links.

## Why it points at the release asset

The link goes to the published release file rather than offering to save the page you are looking at.

*File → Save Page As* serialises the **live DOM**: it writes out the page as it exists in the tab at that moment, including anything a browser extension or injected script has changed, and it rewrites markup on the way out. The result is a file that will not match the checksum published with the release — which means there is no way to tell a clean copy from a tampered one.

The release asset avoids that. It is the exact built artifact, byte-identical to what `ittybitz.app` serves, and GitHub sends it with `Content-Disposition: attachment`, so clicking the link genuinely saves the file rather than opening it.

The link resolves through `/releases/latest/download/`, so it always serves the newest release without being edited each time — the same URL both offline banners already use.

## For users

Nothing to do. If you want a copy of IttyBitz on your own disk, the footer link now gets you one from any page, whether or not you dismissed the banner. Verify what you downloaded with:

```bash
shasum -a 256 ittybitz.html
```

and compare against the checksum published with this release.
